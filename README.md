# 사이별 (saibyeol)

> 같은 나라도, 사이마다 다르게.

내가 아는 사람과의 관계를, 관계마다 다르게 읽어주는 관계 이해 서비스.

현재 상태: https://saibyeol.vercel.app 에 배포되어 있고 카카오 로그인이 동작한다. 기능 1~4 사용 가능. 다음은 관계 매뉴얼.

```
npm install
npm test
npm run demo -w @saibyeol/engine-saju -- 1990-05-15 14:30 1988-12-03 없음
```
